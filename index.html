📌 О проекте

«Гиперболоидный земснаряд и эко-станция» — это комплексная инженерная система, объединяющая две взаимосвязанные задачи:

  • Земснаряд — размыв и углубление русел рек за счёт ускорения потока в гиперболоидных конструкциях. Дешёвый, мобильный, экологичный.
  • Эко-станция — неинвазивное наблюдение за ихтиофауной с помощью ИИ. Аэрация, убежище для рыбы, сбор научных данных.

Система реализована как 8 автоматизированных модулей, которые вместе образуют полный инженерный цикл: от идеи и расчёта CFD до производства и наблюдения за живой рекой.

🔗 Полный пайплайн — 8 модулей

1. print → STL прототипа для 3D-печати 2. validate → Валидация CFD по лабораторным данным 3. calibrate → Коэффициенты потерь (K_in, K_throat, f_darcy) 4. scale → Натурная геометрия и производительность 5. deploy → Производственный пакет (BOM, чертежи, Gantt) 6. eco-observe → ЭКО-станция (железо, сенсоры, якоря) 7. ai-ichthyologist → ИИ-наблюдатель (видео + аудио + eDNA) 8. dashboard → Живой дашборд реального времени 📺
Одна команда — полный цикл:
python hyperdredger_pipeline.py all --workdir ./pechora

🚢 Модули 1–5: Гиперболоидный земснаряд

🐟 Модуль 6: Эко-гиперболоид — станция наблюдения

Эко-станция — это отдельная плавучая установка, предназначенная для неинвазивного наблюдения за ихтиофауной. Она не ловит рыбу, а создаёт комфортную среду и собирает научные данные.

Назначение

  • Аэрация воды в тёплый период
  • Убежище и «точка очистки» для реофильных рыб
  • Наблюдение через сенсоры (без отлова)
  • Сбор данных для ихтиологии

Технические решения

  • Гиперболоид: 3×1.5 м овал, горловина 1 м, длина 8 м
  • Понтон 10×4 м, погружение 3 м
  • 2 гидрокрыла 2.5×1.2 м (стабилизация)
  • Балласт 2.5 т
  • 2 якоря Danforth по 3 т (запас 9.6×)

🤖 Модуль 7: ИИ-ихтиолог — распознавание без отлова

ИИ-ихтиолог — это интеллектуальная система, которая распознаёт рыб по видео и звукам, идентифицирует уникальных особей, ведёт дневник наблюдений и публикует открытые данные.

🎬 Видео-ИИ

  • Backbone: YOLOv8 + ResNet-50
  • Распознавание видов, размеров, поведения
  • Мин. уверенность: 0.65

🔊 Аудио-ИИ

  • Backbone: CNN + Transformer
  • Распознавание по вокализациям
  • Спектрограмма n_fft=2048

🎯 Re-ID

  • Backbone: OSNet
  • Идентификация уникальных особей
  • Порог схожести: 0.80

🐟 Целевые виды (15)

Лосось атлантический (LC) Кумжа (LC) Хариус европейский (LC) Сиг обыкновенный (LC) Нельма (EN) ★ Стерлядь (VU) ★ Щука обыкновенная (LC) Окунь речной (LC) Язь (LC) Лещ (LC) Плотва (LC) Налим (LC) Пелядь (LC) Горбуша (LC) Таймень (VU) ★

📺 Модуль 8: Живой дашборд реального времени

Дашборд на Plotly Dash отображает всё, что происходит на станции, в реальном времени. Работает локально (localhost:8050) или в сети.

📊 Верхняя панель

  • Всего детекций
  • Уникальных видов
  • Уникальных особей
  • O₂ (сейчас)

📈 Графики

  • Timeline детекций по видам
  • T, O₂, поток (3 графика)
  • Пирог видового состава
  • Гистограмма уверенности

🚨 Алерты

  • Редкие виды (★)
  • Низкий O₂ (<4 мг/л)
  • Аномалии поведения
  • Риск замора
Запуск: python hyperdredger_dashboard.py --workdir ./pechora
Открыть: http://127.0.0.1:8050
Автообновление: каждые 5 секунд
