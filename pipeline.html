CLI-конвейер HyperDredger-Optima v1

Единый Python-скрипт: печать прототипа → валидация → калибровка → масштабирование

📌 Обзор

hyperdredger_pipeline.py — это единый CLI-конвейер, который автоматизирует все ключевые этапы разработки гиперболоидного земснаряда: от генерации STL-моделей для 3D-печати до масштабирования на натуру с учётом экономических показателей.

Скрипт поддерживает четыре независимых этапа, которые можно запускать по отдельности или все подряд одной командой. Каждый этап сохраняет артефакты в известные папки и формирует JSON-конфиги для следующего шага.

🚀 Команды

Команда Назначение Артефакты
print STL для 3D-печати прототипа stl_prototype/*.stl
validate Валидация CFD по лабораторным данным stage2_validation.png
calibrate Автокалибровка CFD-параметров calibrated_config.json
scale Масштабирование на натуру fullscale_config.json
all Все четыре этапа последовательно все артефакты
status Состояние проекта (файлы, конфиги) —

💻 Примеры запуска

Установка зависимостей

# Базовые pip install numpy pandas matplotlib # Опционально, для лучшей калибровки pip install scipy

Запуск полного пайплайна

python hyperdredger_pipeline.py all

Запуск отдельных этапов

python hyperdredger_pipeline.py print python hyperdredger_pipeline.py validate python hyperdredger_pipeline.py calibrate python hyperdredger_pipeline.py scale python hyperdredger_pipeline.py status

С параметрами

python hyperdredger_pipeline.py all \ --scale 50 \ --v-river 2.5 \ --depth 10 \ --sediment medium_sand \ --workdir ./pechora_project

🧩 Архитектура пайплайна

Этап 1: print

  • Генерация STL-профилей гиперболоидов
  • Разбиение на секции для печати
  • Фруд-проверка масштаба
  • Выход: *.stl файлы

Этап 2: validate

  • Загрузка/генерация лабораторных данных
  • Сравнение CFD с экспериментом
  • Расчёт R², MAPE, RMSE
  • График рассеяния

Этап 3: calibrate

  • Оптимизация 5 параметров (K_in, K_throat, K_nozzle, f_darcy, C_d)
  • Nelder-Mead + Differential Evolution
  • Fallback: grid search без scipy
  • Сохранение калиброванного конфига

Этап 4: scale

  • Масштабирование геометрии на натуру
  • Расчёт Q, v_горл, P_jet, σ
  • Оценка производительности (м³/смену)
  • Экономика: CAPEX, OPEX, окупаемость

🧮 Ключевые формулы в модели

  • ✅ Q = C_d · A_вх · v_вх
  • ✅ v_горл = Q / A_горл
  • ✅ P_jet = ½ · ρ · Q · v²
  • ✅ σ = (P_горл − P_пар) / (½ · ρ · v_горл²)
  • ✅ τ_дна = F_jet / A_пятна
  • ✅ Производительность = f(τ_дна, τ_крит, грунт)

🎯 Преимущества CLI-подхода

Одна точка входа

Все этапы запускаются одной командой или по отдельности — гибкость без потери целостности.

Стандартизация

Артефакты всегда в известных папках, конфиги унифицированы, результаты воспроизводимы.

Расширяемость

Легко добавить новые стадии: deploy, procurement, drawing_generation и т.д.

Без GUI

Работает на серверах, в CI/CD, в Docker-контейнерах, без графической оболочки.

Совместимость

Работает даже без scipy — есть fallback на grid search. Минимум зависимостей.

Прозрачность

Каждый этап логирует прогресс, метрики и сохраняет отчёт. Легко отлаживать.

✨ Что даёт пользователю

  1. Печатает прототип → готовые STL-файлы для 3D-принтера
  2. Тестирует в лотке → CSV с замерами
  3. Валидирует CFD → R², MAPE, графики
  4. Калибрует коэффициенты → минимизация ошибки модели
  5. Масштабирует на натуру → полный конфиг с экономикой

Всё — одной командой: python hyperdredger_pipeline.py all
